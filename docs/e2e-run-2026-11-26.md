## Bugs found in this run

1. **Bug 2 is still open (medium).** `/priests/nearby?service=test` returns 0 priests. Custom offerings from "My Offerings" are not matched, because the filter only checks `priests.services_offered` (`backend/internal/db/discovery.go:101`).
2. **D3 remainder: stale status and "Could not refresh booking status. Check your connection." after returning to the foreground (low).**
   - Steps: open a booking on the devotee, switch to the priest app and advance a step, then switch back.
   - Seen twice with the network up. The first screen after resume shows the error together with the previous status, and both clear within about 5–8 s.
   - Expected: no error shown, or at least not on the first poll after resume.
3. **New, seen once: priest Duty Radar showed "Status unavailable" and "Could not load availability. Reopen to retry."** on a cold start just after `font_scale` changed to 1.3. The location icon was also missing from the status bar at that moment. The next cold start was fine (D4-H2-priest-font13-30s.png, H2-priest-font13-relaunch.png). Probably a transient failure of the first request after the config change, but there is no automatic retry: the user is told to reopen the app. No crash line.
4. **H2 (minor):** "Pushkaralu" splits mid-word ("Pushkara / lu") in the priest bottom nav at 1.3×.

No new lines in `adb logcat -b crash` during the run.
